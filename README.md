# Francesco Doneddu

### Solidity Security & Verification

I build reproducible security-testing evidence for Solidity smart contracts: written specifications, Foundry tests, fuzzing, invariant checks, mutation testing, and CI workflows.

My focus is making the verification process clear and repeatable. Test coverage and passing tests are useful evidence, but they do not prove that a contract is secure or replace an independent audit.

## Portfolio

- **[MilestoneEscrow Verification](https://github.com/francodoneddu-ctrl/milestone-escrow-verification)** — ETH milestone escrow with a written specification, Foundry test suites, invariant tests, mutation checks, and GitHub Actions.

## Scope and limitations

MilestoneEscrow is a portfolio project developed with AI assistance and reviewed by me. It has not been independently audited, is not suitable for production, and has never been deployed. The EIP-7702 lab is exploratory research, not a vulnerability disclosure or audit finding. No testing engagement can guarantee that a contract is free of vulnerabilities.
